Exemplo de Uso do Widget NPS

Esta página demonstra como utilizar o widget NPS com as novas funcionalidades:

  • Verificação no Supabase se o usuário já avaliou
  • Exibição após 24 horas quando o usuário fecha o widget
  • Suporte para tags (array de strings)

Implementação Básica

<script src="nps-widget.js"></script>
<script>
  initNPSWidget({
    apiUrl: 'https://cxbvqfhdblmlvrgzuqpd.supabase.co/rest/v1/nps_feedback',
    apiKey: 'sua-chave-api',
    primaryColor: '#ea5f3d',
    userId: 'user123',
    email: 'usuario@exemplo.com',
    businessId: 'empresa-abc',
    profile: 'cliente',
    tags: ['website', 'homepage']
  });
</script>
Nota: O widget não será exibido se o usuário já tiver avaliado anteriormente (verificado no Supabase) ou se tiver fechado o widget nas últimas 24 horas.

Parâmetros de Configuração

Parâmetro Descrição Tipo Padrão
userId Identificador único do usuário String 'anonymous'
email Email do usuário String null
businessId Identificador da empresa String null
profile Perfil do usuário String null
tags Array de tags associadas ao feedback Array []
autoOpen Abrir automaticamente após 3 segundos Boolean true

Exemplo com Tags

As tags podem ser usadas para categorizar o feedback e facilitar análises posteriores:

initNPSWidget({
  // Configurações básicas
  apiUrl: 'https://cxbvqfhdblmlvrgzuqpd.supabase.co/rest/v1/nps_feedback',
  apiKey: 'sua-chave-api',
  
  // Identificação do usuário
  userId: 'user123',
  email: 'usuario@exemplo.com',
  
  // Contexto do feedback
  businessId: 'empresa-abc',
  profile: 'cliente',
  
  // Tags para categorização
  tags: ['website', 'checkout', 'mobile']
});

Dica: Você pode usar tags para:

  • Identificar a origem do feedback (website, app, email)
  • Marcar a página ou funcionalidade específica (checkout, perfil, busca)
  • Indicar a versão do produto ou campanha

Visualização no Dashboard

Os feedbacks com tags podem ser filtrados e analisados no dashboard NPS para obter insights mais específicos sobre diferentes aspectos do seu produto ou serviço.
